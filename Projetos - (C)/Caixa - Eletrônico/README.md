 💸 CYPRUS – Caixa Eletrônico em C | Primeiro projeto Após 6 dias de Aprendizado a Linguagem C.
 
CYPRUS é um simulador de caixa eletrônico desenvolvido em C, com interface colorida e distribuição automática de cédulas. O projeto permite que você pratique lógica de programação, funções e manipulação de valores monetários de forma interativa.

Ideal para estudantes e entusiastas que desejam entender a estrutura de um caixa eletrônico de forma simples, clara e funcional.

-📌 Funcionalidades
-🏦 Simulação completa de saques em dinheiro
-💵 Distribuição automática de cédulas: 200, 100, 50, 20, 10, 5, 2, 1
-🎨 Interface colorida no terminal
-🔁 Suporte a múltiplos saques enquanto houver saldo
-🧹 Limpeza automática da tela (cls ou clear)
-⚠️ Validação de entradas inválidas
-📝 Mensagens interativas e explicativas
-🚀 Como Compilar e Executar

*Pré-requisitos:
---------------------------------------------------
Compilador C (GCC, MinGW ou similar)
---------------------------------------------------
Terminal ou prompt de comando:

  Linux / macOS
--Compilar | Linux:
  gcc Caixa_Cyprus.c -o cyprus
--Compilar | Windows (MinGW / GCC):
  gcc Caixa_Cyprus.c -o cyprus.exe
---------------------------------------------------
--Executar | Linux:
  ./cyprus
--Executar | Windows (MinGW / GCC):
  cyprus.exe
---------------------------------------------------
Observação: Em Windows, recomenda-se usar PowerShell para cores ANSI.
